# 最終調査「残された記録」 実装仕様

文化祭の終了後、教室での現場調査は行えなくなった。そのため、最終問題を「教室で見つけたものを答える」形から、「Web上に残された証拠資料を照合する」形に置き換えた。問題の本質（発見した事象と、その危険性の対応づけ）は変えていない。

## 流れ
1. 事件1〜5をすべて終えると、最終調査に進む。
2. 画面の上部に、システムからの通知（FINAL INVESTIGATION）が出る。現場は使えず、残された記録だけが調査対象になる、という内容。
3. 証拠資料（A-01〜A-03）が3枚のカードで表示される。
4. 各証拠について、「そこから分かる事象」と「その危険性」の空欄を、選択肢をタップして埋める。
5. 3組すべて正しければ、INVESTIGATION COMPLETED → FIELD CLEAR。誤答は再回答でき、誤報告には加算しない。
6. 途中でやめたいときは、タイトルバーの「リタイア」（0点。結果画面に照合結果が出る）。

## データ（`cases.js` の `id: "c4"`）
| キー | 内容 |
|---|---|
| `intro` | 画面上部の通知文（FINAL INVESTIGATION） |
| `evidence` | 証拠資料。`no`（A-01など）、`title`、`meta`、`text` |
| `final.rows` | 正解の組。`ev`（証拠番号）、`place`（問題文の前半）、`incident`、`risk` |
| `decoys` | ハードモードでだけ選択肢に混ぜるダミー（`incident` と `risk`） |
| `notice` | クリア時の文言 |
| `source` | 出典・注記（架空の資料である旨） |

証拠を増やすときは、`evidence` と `final.rows` に同じ数だけ足す。選択肢は毎回シャッフルされる。得点は1組50点（ハードモードは1.5倍）。

## 注意
- 証拠資料は、すべて架空のもの。実在の端末・メール・アカウント・個人を使わない。
- 「最終更新：文化祭開催期間中」は、世界観に合わせた表記。
